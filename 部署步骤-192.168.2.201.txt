七、配置 Nginx (在 201 上)
--------------------------------------------------------------------------------
sudo tee /etc/nginx/sites-available/sikong-cloud <<'EOF'
server {
    listen 80;
    server_name _;

    # 大屏
    location /screen/ {
        alias /opt/sikong-cloud/screen/;
        try_files $uri $uri/ /screen/index.html;
    }

    # 后台管理
    location /admin/ {
        alias /opt/sikong-cloud/admin/;
        try_files $uri $uri/ /admin/index.html;
    }

    # H5
    location /h5/ {
        alias /opt/sikong-cloud/h5/;
        try_files $uri $uri/ /h5/index.html;
    }

    # API 反代
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 图片静态资源
    location /zhimou-img/ {
        alias /opt/sikong-cloud/zhimou-images/;
    }

    # 标注图
    location /api/image-detect-img/ {
        proxy_pass http://127.0.0.1:8080/api/image-detect-img/;
    }
}
EOF

sudo ln -sf /etc/nginx/sites-available/sikong-cloud /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t  (测试配置)
sudo systemctl restart nginx
sudo systemctl enable nginx


八、配置后端服务 (systemd 开机自启)
--------------------------------------------------------------------------------
sudo tee /etc/systemd/system/sikong-cloud.service <<'EOF'
[Unit]
Description=Sikong Cloud API
After=network.target redis-server.service

[Service]
Type=simple
User=nvidia
WorkingDirectory=/opt/sikong-cloud
ExecStart=/usr/bin/java -Dspring.profiles.active=base,company-a -jar /opt/sikong-cloud/sikong-cloud-api-1.0.0.jar
Restart=on-failure
RestartSec=10
StandardOutput=append:/opt/sikong-cloud/logs/app.log
StandardError=append:/opt/sikong-cloud/logs/app.log

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable sikong-cloud
sudo systemctl start sikong-cloud

十、外网映射 (如果需要外网访问)
--------------------------------------------------------------------------------
路由器/防火墙上配置端口映射:
  外网 223.113.158.186:50080 → 内网 192.168.2.201:80

同时修改 h5.host 为外网地址 (短信链接用):
  h5.host: 223.113.158.186:50080

注意: callback-url 不要改成外网地址!
  保持: http://192.168.2.201:8080/api/zhimou/callback (内网直连)
  原因: 外网 IP 带端口会导致 yml 变量拼接出双端口 (50080:8080)


十一、踩坑记录 (必读)
--------------------------------------------------------------------------------
1. callback-url 不能用外网 IP 带端口
   错误: http://223.113.158.186:50080:8080/api/zhimou/callback (双端口!)
   正确: http://192.168.2.201:8080/api/zhimou/callback

2. h5.host 和 callback-url 是分开的, 不要全局替换 IP
   h5.host 可以带端口 (外网用)
   callback-url 不要带外网端口

3. Spring Boot 2.7 的 Redis 前缀是 spring.redis (不是 spring.data.redis)
   错误: spring.data.redis.host
   正确: spring.redis.host

4. 启动参数: -Dspring.profiles.active=base,company-a
   不是 test (没有 application-test.yml)

5. 前端 dist 必须重新构建 (不能用旧 dist)
   特别是 admin-v3, 新增了照片告警页面

6. 知眸图片保存目录和 MinIO 临时目录要用 Linux 路径
   错误: H:/traeproject/zhoudao/zhimou-images
   正确: /opt/sikong-cloud/zhimou-images
